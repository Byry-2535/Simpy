# 🐱‍💻 Simpy — Your Fun System Info Cat

A hundred lines Python script inspired by neofetch and fastfetch that stylishly displays key system info with an ASCII cat.

---

## 🌟 Features

✨ **What Simpy Shows:**
- 👤 User
- 🖥️ CPU
- 💾 RAM & disk usage
- 🔋 Battery status (if present)
- ⏱️ System uptime
- 😺 Cute ASCII cat for extra charm

---

## 🚀 How to Run

1. Download **[`simpy.exe`](https://github.com/Byry-2535/Simpy/raw/main/simpy.exe)**.
2. Double-click to run.
3. Watch your system info appear with a friendly cat!
